Open-world crime game: an original city "Vice Shores" — on foot and by car,
traffic and pedestrians, steal cars, wanted level and police, missions and a
story, combat, HUD and minimap, start and save. Built with three.js (vendored),
playable offline in a desktop browser.

Entry for [Make GTA 6](https://make.fun/bounty/gta6-01) on make.fun.
